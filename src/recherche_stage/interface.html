    Préférences de rédaction
    

      
Pour toutes les lettres. Ex. : « Mettre en avant mon parcours académique (prépa, école d'ingénieur, matières). Ne citer le TIPE qu'en une phrase, et seulement s'il est en lien avec le poste. »
        Le rédacteur n'invente jamais rien : il choisit seulement quoi mettre en avant dans ton profil.

      
      

    

  


  

    Réglages
    

      
Zone, secteurs, rythme, dépôts sur place et sur les sites carrière. Écrits dans config.yaml (l'ancienne version est gardée dans config.yaml.precedent). Les clés et mots de passe ne se règlent jamais ici : ils restent dans les variables d'environnement.
